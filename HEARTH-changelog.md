# Hearth — Changelog

Detailed entries for the newest ~10 versions. Older entries live in `HEARTH-archive.md`.

**Do NOT read this file end to end at session start** — read only the entries for the versions you are actually touching. Architecture and working notes are in `HEARTH-notes.md`; pending work is in `HEARTH-backlog.md`.

## ✍️ How to write an entry (added 16/08/2026)

Entries here had grown to 500–2,800 words each, written by the most expensive model at the end of the longest context in the session — and the detail was already in the PR, which is permanent and searchable. New entries are capped:

- **A headline sentence** — what changed, and the date, in the existing bold style.
- **Up to ~150 words** of substance: the mechanism, the non-obvious decision, the test that pins it.
- **Every "do NOT simplify this into X" warning**, in full — these are the entries' real value and are exempt from the cap.
- **A link to the PR** for the full reasoning. Do not reproduce the PR body here.

If a change genuinely needs more (a shipped incident, a new subsystem), write the long version in its own doc and link it, as `HEARTH-freeze-analysis.md` and `HEARTH-global-search.md` already do.
